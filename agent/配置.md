```json
{
  "railwayDataProtection": true
}
```

当前唯一开关`railwayDataProtection`控制整套铁路DAT保护：启动预检、严格读取/Gzip与结构校验、原子保存和失败后的阻断。缺文件、缺键或false默认关闭；必须使用JSON布尔值，字符串、数字、null等非法配置会记录警告并保持关闭。读取失败同样警告后关闭，不会悄悄声称保护已启用。未知键保留扩展空间，当前不产生行为。

只在专用服务器启动时读取一次。单人及对局域网开放的集成服务器无条件关闭，不读取此配置，即使误带true也不会开启。改配置需要重启。启用状态按该服务器主世界铁路DAT路径记录，启动重置、停止清理，避免跨世界残留。关闭时读取Mixin调用原方法，保存Mixin在取消原方法之前返回，完整沿用原版/Create读写；其他TrainResync功能不受开关影响。

专用服启用时保留1.6.0.k的首次初始化识别；真实坏DAT、遗留`.trainresync.tmp`及已初始化旧世界缺DAT仍阻断。保护关闭不等于会修复损坏数据；以后重新开启还会检查已有文件。
